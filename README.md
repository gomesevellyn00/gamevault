# GameVault

Aplicação web para organizar uma biblioteca pessoal de jogos, desenvolvida com HTML, CSS e JavaScript.

## Sobre o projeto

O GameVault foi criado a partir de um tema que eu gosto muito: jogos.

Para deixar o projeto mais pessoal, usei títulos da minha própria biblioteca de jogos, incluindo jogos que já joguei, estou jogando ou acompanho.

A ideia foi criar uma aplicação onde seja possível organizar a biblioteca, acompanhar progresso, avaliações, horas jogadas e favoritos.

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript
- LocalStorage

## Funcionalidades

- Biblioteca de jogos com capas
- Pesquisa por nome
- Filtro por gênero
- Filtro por status
- Filtro de favoritos
- Ordenação por nome
- Ordenação por nota
- Ordenação por horas jogadas
- Sistema de favoritos
- Avaliação de 1 a 5 estrelas
- Registro de horas jogadas
- Status: Sem status, Quero jogar, Jogando e Finalizado
- Adição de novos jogos
- Remoção de jogos
- Modal com detalhes
- Dados salvos no navegador com LocalStorage
- Layout responsivo
